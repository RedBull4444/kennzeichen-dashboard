# kennzeichen-dashboard

Weboberfläche für den Kennzeichen-Scanner. Enthält keine Daten: Watchlist und Ergebnisse liegen im privaten Repo `kennzeichen-scanner` und werden mit einem persönlichen GitHub-Schlüssel geladen, der nur im Browser des jeweiligen Geräts gespeichert ist.
